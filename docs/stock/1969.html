この会社は何者か

空調設備工事を本業とする設備サブコンである。建物の空気と熱を扱う設備を、設計から施工、その後の保守まで請け負う。1923年11月に高砂煖房工事株式会社として設立され、1943年7月に現社名へ改称した†。東京証券取引所には1969年11月に上場（市場第二部）、1973年8月に第一部へ指定替え、2022年4月から東証プライム市場に所属する†。

事業は3つに分かれる†。

  • 設備工事事業 — 本体の空調設備の設計・施工に加え、TMES株式会社が保守・設備総合管理を担う。海外は中国・香港・シンガポール・ベトナム・タイ・マレーシア・メキシコ・インドに連結子会社を持つ
  • 設備機器の製造・販売事業 — 日本ピーマック株式会社が空調機器を設計・製造・販売する
  • その他 — ヒューコス株式会社の保険代理店業

比重は設備工事事業に大きく偏っており、2027年3月期1Qの連結売上高 84,922百万円† のうち 82,984百万円† がこのセグメントである（97.7%†）。連結子会社は15社、持分法適用関連会社は2社、単体の従業員数は2,469名（2026年3月末）†。

工事の中身は会社の開示上「一般設備」と「産業設備」に分かれる†。一般設備はオフィスビル・商業施設・教育施設・データセンターなど、産業設備は半導体・電子部品・電池・医薬などの工場とクリーンルームを指す。この2つは景気の当たり方も工期も採算も違うので、以下の節でも分けて見る。

工事会社なので、損益計算書に出てくる数字は数年前に取った仕事の結果である。順番としては、受注 → 繰越工事高（受注残）→ 完成工事高（売上）と流れる。今期の売上を見て将来を語るのではなく、受注残を見るのが筋になる。

この台帳に載っているのは、AI データセンターを「建てる側」を層に切ったときの D3（空調・冷却工事）の顔ぶれとして拾ったためである（segments/ai-datacenter-build.yaml）。この層の供給制約は有資格の人で、年単位でしか増えない——という仮説の検証対象として登録した。同じ層の比較対象として 1952・1961・1979・1980 を peers に置いている。

目を引くのは利益率のほうである。売上高は2023年3月期から2026年3月期で 1.25倍にしかなっていないのに、営業利益は 15,326百万円✓ から 47,745百万円✓ へ3倍を超えた。営業利益率は 8.49%✓（2025年3月期）から 11.26%✓（2026年3月期）へ上がっている。会社は理由として、元請とコストオンの比率上昇による受注時採算の改善、生産性向上、海外子会社の採算改善を挙げている†。受注における元請＋コストオン比率は2023年度の 60.9%† から2026年度1Qの 63.8%† まで上がった。

財務は厚い。自己資本比率は 48.3%✓（2024年3月期）→ 53.9%✓ → 55.0%✓ と上がり続け、2027年3月期1Q末は 58.9%† である。2026年3月期の現金及び現金同等物は 42,537百万円✓、営業キャッシュフローは 29,725百万円✓、フリーキャッシュフローは 17,885百万円✓。

ただし建設業のキャッシュフローは工事代金の回収と支払の時期でよく振れる。2024年3月期の営業キャッシュフローは △13,100百万円✓ とマイナスだった。単年の営業CFで健全性を判断してはいけない類の会社である。総資産も 2026年3月期末 381,823百万円✓ から1Q末 351,491百万円† へ3か月で約8%減っており、会社は受取手形・完成工事未収入金及び契約資産の減少が主因と説明している†。

有利子負債は取得元が1つしかなく照合が成立していない（IR BANK 単独で 42,400百万円※）。master.yaml の valuation_model は per_netcash（純現金控除PER）だが、純現金を確定できないためこの軸での評価は出していない（「値動きと市場の評価」節を参照）。

株主還元は配当性向40%目途の累進配当を基本方針としている†。2027年3月期の年間配当予想は123円（中間61円・期末62円）†、2026年3月期は分割後換算で115円† だった。自己株式取得は2025年4〜6月に約80億円を実施済み†。

四半期の営業利益率は 7.34%✓ から 14.52%✓ の間で振れている。四半期1本で傾向を読むと必ず間違える。

今後の展望とリスク

会社計画（2026年5月12日公表、1Q時点で据え置き†）は売上高 440,000百万円✓・営業利益 50,000百万円✓・経常利益 52,000百万円✓・純利益 40,000百万円✓。加えて受注高は 520,000百万円†、期末の繰越高は 491,574百万円† を見込む。会社は受注計画について「初の5,000億円を超える受注計画」と書いている†。中期経営計画2026（2023〜2026年度）は2026年度が最終年度で、KGI の連結経常利益は当初の400億円から520億円へ引き上げられている†。

受注残は積み上がっている。 2027年3月期1Q末の連結繰越高は 433,250百万円†（前年同四半期末比 +12.2%†）。ただし内訳を見ると話が変わる。

  • 一般設備 268,824百万円†（+26.5%†）
  • 産業設備 160,973百万円†（△5.8%†）

伸びているのは一般設備のほうで、産業設備は前年同四半期末を下回っている。1Q単独の受注高は 106,598百万円†（前年同四半期比 +1.7%†）で、決算説明資料の推移では 2024年度1Q 1,005億円† → 2025年度1Q 1,047億円† → 2026年度1Q 1,065億円† と3年続けて増えている。

「データセンター銘柄」として見ると実態とずれる。 単体の繰越工事高に占めるデータセンターの比率は 3.7%†、1Q の受注工事高では 2.1%† にとどまる。同じ内訳で工場（産業設備）は繰越の 29.9%†、事務所は 32.1%† を占める。会社は決算説明会で、データセンター関連の営業情報量が減った理由を「受注計上のタイミング予定を今期から来年度に移したこと等による」と説明している†。データセンターがこの会社の主戦場になっているのではなく、半導体工場と首都圏の再開発オフィスが主戦場で、データセンターはそこに乗る一部——というのが現時点で開示から読める姿である。会社は再開発オフィスについて「現段階の繰越工事で2029年頃まで安定して寄与する見通し」と述べている†。

リスクとして見ているのは次の5つ。

  1. 四半期の偏り。 会社は「今期の完工高は第3・4四半期の比重が高い計画」と明言している†。1Qの減収減益（売上 △9.9%†・営業利益 △16.2%†）は前期1Qに産業設備の大型案件の出来高が集中した反動であり、会社は1Qの完工高を「概ね計画通り」としている†。それでも、通期計画の達成は下期に賭ける形になる
  2. 熊本の地震。 令和8年熊本地震（2026年7月28日・最大震度7）で熊本県の半導体各社の工場が一時停止した（二次情報）。会社は通期予想を据え置いた理由として「熊本地震や中東情勢影響などの不確実性」を挙げている†。産業設備の受注・出来高への影響は現時点で数字として開示されていない
  3. 供給の制約が人であること。 中期経営計画2026 の KPI「社員数350名増加」に対して2025年度末で400名増†、2027年4月入社の内定者は採用計画120名に対し137名†。会社は「現場代理人が増えなければ、より多くの工事を受けることが出来ない」と説明している†。これは裏を返せば、需要があっても人がいなければ売上にならないということである
  4. 受注時採算が維持できるか。 利益率の上昇は元請＋コストオン比率の上昇に支えられている†。会社自身が「建設物価の高騰は、お客様の投資判断に影響を及ぼすこともある」と述べており†、発注側の投資計画が止まれば採算改善の前提が崩れる
  5. セグメント仮説の反証条件。 segments/ai-datacenter-build.yaml の F2 は「受注残が2期連続で減少し、営業利益率が低下に転じる」を取り下げ条件に置いている。産業設備の繰越高が前年割れした（△5.8%†）のは、その半分が点灯したというより、まだ一般設備が補っている段階と読める。次の四半期で連結の繰越高そのものが減るかどうかが分かれ目になる

値動きと市場の評価

直近の採用終値は 4,361円✓（2026年8月27日）。52週の窓では安値 3,987円✓（2025年10月2日）・高値 5,683円✓（2026年2月12日）で、高値からは2割超下、安値からは1割弱上の位置にある。取得している270営業日のうち、2つの取得元が一致して採用できた終値は223日ぶん（OK を含む行の数）で、残りは片方しか取れなかった日と食い違った日である。

株価から導いた指標は次のとおり。いずれも採用値どうしの割り算だが、指標そのものは照合を経ていないので参考値として扱う。

  • PER 約14.3倍※（会社計画EPS 305.6円✓ 基準）／約15.3倍※（2026年3月期実績EPS 285.73円✓ 基準）
  • PBR 約2.7倍※（BPS 1,603.89円✓ 基準）
  • 配当利回り 約2.8%※（2027年3月期の年間配当予想123円† 基準）
  • 時価総額 — 出さない（発行済株式数の出典を確かめられていないため。確かめ次第入れる。埋めて完全に見せるより欠測を残す）

流動性は十分にある。直近20営業日（採用終値のある日）の平均売買代金は約31億円※で、master.yaml の流動性ゲート（20日平均売買代金 3,000万円）を大きく上回る。信用取引は2026年8月21日時点で買残 360.6千株※・売残 35.4千株※・倍率 10.19倍※と買い長である。

評価軸としては、いまは止まっている。 valuation_model は per_netcash（純現金控除PER）だが、有利子負債の照合が成立していないため純現金が確定できず、この銘柄に定められた手法での割安・割高の判定を出していない。単純PERで14〜15倍※という水準だけを見て結論を出すことはしない。

2026年2月12日の 5,683円✓ から現在までの下落については、この台帳のデータから理由を特定できていない。むしろ会社側の材料は上向きだった。 高値の翌日にあたる2026年2月13日、会社は2026年3月期の通期予想を営業利益 43,300百万円† → 47,100百万円† へ引き上げ、期末配当も1株62円† → 69円† へ増額している。実績はさらにその上（営業利益 47,745百万円✓）で着地した。株価がこの間に2割超下げた説明は、開示からは付いていない。
